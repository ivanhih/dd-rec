# 界面导览

## 频道页（主页）

房间以卡片展示，常见信息/操作：

- 直播状态（离线 / 监控中 / 录制中）
- 录制时长、速度、文件大小
- 监听开关
- 手动切割
- 打开输出目录
- 进入房间设置 / 删除房间

## 添加直播间

1. 点击添加
2. 输入房间号或直播间 URL
3. 程序后台请求 B 站 API 拉取房间信息
4. 成功后生成房间卡片

## 设置页（全局）

全局设置覆盖所有房间的默认策略，通常包括：

- **录制**：切割时长/大小、标题/分区变化切割、流编码与清晰度、自动切更好流
- **保存**：默认目录、输出/转换格式
- **监控 / 通知 / 外观 / 系统**：轮询策略、Webhook、主题语言、开机自启、防止休眠等

> 实际表单会随版本迭代增减；以软件内设置为准，字段含义见 [配置参考](配置参考)。

## 房间设置

房间级覆盖全局项，典型可配：

- SESSDATA / Cookie（留空继承全局）
- 输出格式、清晰度
- 自定义保存目录

## 关于页

- 当前版本
- 打开日志 / 日志目录
- 检查更新
- 日志查看器 overlay（可按 INFO / WARNING / ERROR / 崩溃筛选）
