# 配置参考

配置文件：

```text
<程序根>/userdata/config.json
```

首次启动会生成默认配置。也可参考仓库中的 [`config.example.json`](https://github.com/ivanhih/dd-rec/blob/master/config.example.json)。

> 下表描述 **1.0.5 代码默认语义**。UI 文案可能是中文展示值，落盘时以实际 JSON 为准。

## 顶层结构

```json
{
  "global_settings": { },
  "global": { "default_save_dir": "..." },
  "rooms": {
    "<room_id>": { }
  }
}
```

## 常用 global_settings

### 外观与系统

| 键 | 含义 | 典型值 |
|----|------|--------|
| `language` | 界面语言 | `简体中文` / `繁體中文` / `English` |
| `theme` | 主题 | `深色` / `浅色` |
| `auto_start` | 开机自启 | `true/false` |
| `prevent_sleep` | 防止休眠 | `true/false` |
| `update_channel` | 更新下载通道 | `github` / `cnb` |

### 流与录制

| 键 | 含义 |
|----|------|
| `stream_record_enabled` | 是否录视频流 |
| `stream_resolution` | 清晰度偏好 |
| `stream_codec` | 编码偏好（默认 `h264`） |
| `stream_format` | 容器/协议偏好（默认 `flv`） |
| `stream_fps` / `stream_bitrate` | 帧率、码率偏好 |
| `auto_switch_stream` | 自动切换更好的流 |
| `allow_audio_only` | 是否允许纯音频 |
| `stream_fallback_policy` | 找不到目标组合时的回退策略 |
| `flv_native_capture` | 启用原生/桥接 FLV 管线 |
| `flv_cdn_speed_window_sec` | 媒体速度采样窗口，默认 20 秒 |
| `flv_cdn_slow_speed_ratio` | 慢流速度阈值，默认 0.8 倍实时速度；与累计延迟联合判断 |
| `flv_cdn_recovery_speed_ratio` | 稳定恢复速度阈值，默认 0.95 倍实时速度 |
| `flv_cdn_recovery_sustain_sec` | 稳定恢复验证窗口，默认 20 秒 |
| `flv_cdn_media_stall_sec` | 已有媒体后持续无媒体进度的阈值，默认 15 秒 |
| `flv_cdn_refresh_interval_sec` | 候选刷新基础间隔，默认 30 秒，失败退避并加入房间抖动 |
| `flv_cdn_allow_quality_change` | 换源时允许接口返回不同画质，默认关闭；编码和格式仍保持锁定 |

### 切割

| 键 | 含义 |
|----|------|
| `split_by_duration` | 按时长切，如 `01:00:00` |
| `split_by_size` | 按大小切，如 `2GB` |
| `split_on_title_change` | 标题变化切割 |
| `split_on_category_change` | 分区变化切割 |
| `split_on_codec_change` | 编码变化切割 |
| `split_on_stream_discontinuity` | 流中断切割 |

### 路径与产物

| 键 | 含义 |
|----|------|
| `save_dir` | 默认保存根目录 |
| `path_template` | Liquid 路径模板 |
| `download_cover` | 下载封面 |
| `convert_enabled` / `convert_format` | 遗留转换开关/目标格式 |
| `artifact_profile` | 后处理配置档 |
| `artifact_keep_source` | 是否保留源捕获文件 |
| `artifact_strict_decode_validation` | 严格解码校验 |
| `webhook_only_verified_artifacts` | 仅校验通过才 webhook |

### 弹幕 / Webhook / 通知 / 监控

| 键 | 含义 |
|----|------|
| `chat_record_enabled` | 弹幕开关 |
| `chat_format` | 弹幕格式 |
| `chat_credential` | 弹幕凭证 |
| `webhooks` | Webhook URL（可多条，按实现分隔） |
| `webhook_format` | 如 `blrec` |
| `notify_enabled` / `notify_url` | 远程通知 |
| `notify_on_live_end` / `notify_on_error` | 通知触发条件 |
| `monitor_delay` / `monitor_interval` / `monitor_concurrency` / `monitor_debounce` | 监控节奏 |
| `proxy` / `proxy_mode` / `proxy_bypass` | 代理 |

### 录制条件 / 计划

| 键 | 含义 |
|----|------|
| `condition_title` | 标题条件 |
| `condition_category` | 分区条件 |
| `condition_time_range` | 时间段条件 |
| `schedule_timezone` / `schedule_start` / `schedule_stop` | 计划录制窗口 |

## 房间级覆盖

`rooms.<room_id>` 可覆盖全局项，常见：

- Cookie / SESSDATA
- 自定义目录
- 清晰度 / 格式
- 是否启用监听
- 房间专属通知开关等

未设置的键继承 `global_settings`。
