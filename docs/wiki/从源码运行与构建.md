# 从源码运行与构建

## 环境

- Python **3.11+**（开发中验证过 3.14）
- Windows 10/11
- 依赖见仓库 [`requirements.txt`](https://github.com/ivanhih/dd-rec/blob/master/requirements.txt)
  - PySide6、requests、curl-cffi、python-liquid、markdown 等
- 本机 FFmpeg（建议 `C:\ffmpeg\bin\ffmpeg.exe`）

## 源码运行

```bash
git clone https://github.com/ivanhih/dd-rec.git
cd dd-rec
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 测试

```bash
python -m unittest discover -s tests -v
```

## 构建

版本号唯一来源：[`version.py`](https://github.com/ivanhih/dd-rec/blob/master/version.py)

```bash
python build.py
```

完整流水线（概要）：

1. 清理旧产物
2. PyInstaller 打包主程序
3. 生成 kachina update / 组装 Portable 目录
4. 生成 metadata / 7z / 安装器
5. 可选 HDiff 差分补丁
6. 复制 release 资产

简化脚本 `build_simple.py` 可打 zip 版 Portable（跳过部分 kachina 步骤）。

更多发布细节见仓库 [`RELEASE.md`](https://github.com/ivanhih/dd-rec/blob/master/RELEASE.md) 与本 Wiki 的 [发布与自动更新](发布与自动更新)。
