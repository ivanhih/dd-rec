# 路径与数据目录

## Portable 根目录

打包运行时，程序根目录是 `dd_rec.exe` 与 `version.ini` 所在目录：

```text
<portable_root>/
  dd_rec.exe
  version.ini
  ffmpeg/
  _internal/            # PyInstaller 运行时（onedir）
  dd_rec.update.exe     # 更新器（若已打包）
  userdata/             # 用户配置与日志（更新时保留）
  录播文件/              # 默认视频目录（更新时保留）
```

源码运行时，portable 根 = 项目根目录。

## userdata

```text
userdata/
  config.json
  data.json
  log/bilirec.log
  log/crash.log
  ...
```

- **跨更新保留**：安装器 / kachina 配置会忽略 `userdata`
- 不要把手动改配置和录播大文件混在同一目录策略里；视频默认在 `录播文件/`

## 录播文件目录

- 默认：`<portable_root>/录播文件/`
- 可被 `save_dir` 或房间 `custom_dir` 覆盖
- 最终相对路径由 `path_template`（Liquid）渲染

## 路径模板变量（常用）

模板引擎：`python-liquid`

常见变量：

| 变量 | 含义 |
|------|------|
| `download_dir` / `out_dir` | 下载根 / 输出根 |
| `channel` | 房间号等频道标识 |
| `user_name` | 主播名 |
| `title` | 标题 |
| `platform` | 平台标识 |
| `ctime` | 创建时间（可 `date` 过滤） |
| `format` | 扩展名/格式 |

默认模板大致按「根目录 / 频道-主播 / 日期 / 平台-频道-标题-时间.格式」组织，具体以当前 `config.json` 为准。
