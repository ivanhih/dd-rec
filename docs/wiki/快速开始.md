# 快速开始

## 系统要求

- Windows 10 / 11
- 可访问 `live.bilibili.com` 及相关 API
- 打包版已内嵌 FFmpeg；源码运行需本机可用 FFmpeg

## 下载安装

1. 打开 [Releases](https://github.com/ivanhih/dd-rec/releases)
2. 选择其一：
   - **`dd_rec.Install.<version>.exe`**：安装版（kachina 安装器）
   - **`dd_rec-<version>-portable.7z`**：Portable 绿色版
3. 安装或解压后运行 `dd_rec.exe`

> 程序可能未代码签名。首次运行若被 SmartScreen 拦截，请确认来源后选择“仍要运行”。

## 第一次使用

1. 启动程序，等待启动页结束后进入主界面
2. 在**频道页**添加直播间：
   - 输入房间号，或 `live.bilibili.com` 链接
3. 确认房间卡片出现后，打开该房间的**监听开关**
4. 开播后自动开始录制；卡片会显示状态、时长、速度、大小
5. 需要时在**设置页**调整清晰度、保存目录、切割、弹幕、Webhook

## 默认数据位置

程序根目录下（安装目录或 Portable 解压目录）：

```text
dd_rec.exe
version.ini
ffmpeg/
userdata/          # 配置、日志、缓存
录播文件/           # 默认视频输出目录
```

详见 [路径与数据目录](路径与数据目录)。

## 建议的初始设置

| 场景 | 建议 |
|------|------|
| 稳定性优先 | 编码 `h264`，格式 `flv`（默认迁移目标，利于原生捕获） |
| 硬盘空间 | 开启按时长切割（如 `01:00:00`），后处理输出 `mp4` |
| 需要弹幕 | 开启聊天录制，格式按下游工具选择 jsonl / xml / ass |
| 对接上传 | 配置 Webhook（blrec 格式） |
