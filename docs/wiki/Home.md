# DD录播机

当前版本：**1.0.8**。DD录播机是面向 Windows 的 B 站直播录制客户端，支持多房间监控、弹幕录制、分段保存和录制后处理。

## 开始使用

在频道页添加直播间并开启监听。录制文件默认保存在软件数据目录下的“录播文件”文件夹；FFmpeg 用于处理直播流及录制后的媒体文件。

## 登录与录制

扫码登录是可选功能。登录后可让房间共用 B 站账号 Cookie，适用于需要登录态的直播间；账号信息只保存于本机 `userdata/bili_account.json`。不登录时仍可匿名录制公开直播，也可以在房间设置中选择匿名模式。

## 设置与数据

全局设置用于调整录制格式、画质、保存路径、切割规则和通知方式。账号、配置和日志保存在软件数据目录的 `userdata` 中。

更多账号使用说明见随软件附带的扫码登录与录制账号文档。
