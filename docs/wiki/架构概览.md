# 架构概览

面向贡献者与二次开发者的简图。

## 目录

```text
main.py                 # 入口 / 主窗口编排
version.py              # 版本唯一来源
core/
  bili_api.py           # B 站直播 API
  recorder.py           # 单房间录制主循环
  stream_source.py      # HTTP-FLV 拉流
  ffmpeg_flv_source.py  # FFmpeg→FLV 桥接源
  flv/                  # 原生 FLV 解析与分段会话
  media_pipeline.py     # 关闭后校验/remux
  danmaku_recorder.py   # 弹幕
  config.py             # 配置、路径、迁移
  portable_updater.py   # 更新检查
  http_ssl.py           # 进程级共享 SSL
  power.py              # 防止休眠等
ui/
  room_card.py          # 房间卡片
  settings_dialog.py    # 设置 / 添加房间
  theme.py / i18n.py    # 主题与多语言
  log_viewer_dialog.py  # 日志查看
tests/                  # 单元与 UI 冒烟
build.py                # 发布构建
```

## 运行时数据流

```text
UI (房间开关)
  → BiliRecorder 线程
      → 监控开播 / 选流 (bili_api)
      → 捕获
         ├ native FLV (StreamSource + FlvCaptureSession)
         ├ FFmpeg FLV bridge (FfmpegFlvSource + FlvCaptureSession)
         └ FFmpeg 直录
      → 分段关闭
         → MediaPipeline（校验/remux）
         → Webhook / UI 信号
      → DanmakuRecorder 并行落盘
```

## 关键线程原则

- 网络与录制在后台线程
- UI 更新需回到主线程（信号建议队列连接）
- 媒体后处理回调先入队，再由 recorder 线程 drain 后 emit，避免跨线程碰 QObject

## 配置迁移

`apply_config_migrations()` 负责旧配置兼容，例如：

- 历史默认 `av1/fmp4` → `h264/flv`
- 旧 `convert_delete_source` → `artifact_keep_source`
- 清理废弃键（如 mirror 相关）

迁移幂等，带标志位，避免覆盖用户事后改回的选择。
